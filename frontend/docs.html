RAG (Retrieval-Augmented Generation)

How RAG Works in BoneQuest

1

Document Processing

PDFs are extracted and chunked into 1500-word segments with 100-word overlap

2

Retrieval

TF-IDF search finds relevant chunks with partial matching and scoring

3

Generation

LLaMA model generates responses with inline citations [1][2][3]

Deployment Guide

Local Development

# Clone repository
git clone <repository>
cd BoneQuest-RAG

# Install dependencies
pip install -r requirements.txt

# Set environment variables
echo "GROQ_API_KEY=your_groq_api_key" > .env

# Run application
python backend/main.py

# Access at http://localhost:8000

Render Deployment

1. Connect Repository

Link your GitHub repository to Render

2. Environment Variables

Set GROQ_API_KEY in Render dashboard

3. Deploy

Uses render.yaml configuration for automatic deployment

Docker Deployment

# Build image
docker build -t bonequest .

# Run container
docker run -p 8000:8000 -e GROQ_API_KEY=your_key bonequest
